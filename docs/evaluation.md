# Response Evaluation

Humor is subjective, so Memebot uses a qualitative checklist.

A response is better when it is:

- immediately understandable
- shorter than the setup
- surprising without being random
- consistent with the bot personality
- visually clean in a screenshot
- not dependent on an explanation

| Dimension | Question |
|---|---|
| Clarity | Does the joke make sense on first read? |
| Brevity | Can anything be removed? |
| Voice | Does it sound like Memebot? |
| Novelty | Is there an unexpected turn? |
| Reusability | Could someone actually post or send it? |
